# Cdxtest

Лендинг «Польза витамина D3 в России»

## Что внутри
- Современный тёмный UI с трендами 2025 года: градиенты, стекломорфизм, шум, container queries и анимированные элементы.
- GSAP 3 для плавных появлений и анимации приборной шкалы.
- Адаптивная сетка для мобильных и десктопов.

## Как запустить
Откройте `index.html` в браузере или поднимите простой сервер, например:

```bash
python -m http.server 8000
```

и перейдите на `http://localhost:8000`.

## Деплой на Vercel

1. Установите CLI: `npm i -g vercel`.
2. Авторизуйтесь: `vercel login`.
3. Запустите предпросмотр: `npm run preview`.
4. Продакшн: `npm run deploy`.

Конфигурация `vercel.json` включает кэширование статических CSS/JS и чистые URL. Для локальной проверки используйте `npm run dev`.
